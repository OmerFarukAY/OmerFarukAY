I am a Computer Engineering undergraduate at **Ostim Technical University**, building production-ready **mobile**, **web**, and **AI-assisted** products. I care about clean architecture, human-centric UI, and systems that stay fast under real usage — from Flutter apps with RBAC to realtime voice agents and RAG pipelines.

- 🏢 **Currently:** Software Engineering Intern at Cyberverse — LiveKit / WebRTC, OpenAI Realtime, domain taxonomy & RAG, clinician-facing web + Expo consoles
- 📱 **Core craft:** Cross-platform mobile (Flutter, Dart, Riverpod, Expo) and modern web (React 19, Next.js, Tailwind)
- 🤖 **Building with AI:** Claude & OpenAI integrations, RAG retrieval, Telegram/voice agents, evidence-grounded decision support
- 🧩 **Also shipping:** FastAPI + PostgreSQL research platforms, Firebase-backed Flutter apps, Dockerized personal infrastructure
- 🤝 **Looking to collaborate on:** Open-source Flutter/React apps, AI product UX, and realtime systems
