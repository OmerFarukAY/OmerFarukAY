### 👨‍💻 About Me

Computer Engineering student at **Ostim Technical University**. I design end-to-end products: native-feeling mobile clients, modern web consoles, and the backends / AI layers that make them useful.

These days that means **low-latency voice (LiveKit / WebRTC)**, **RAG over structured knowledge**, **Flutter + Expo apps**, and **Next.js / FastAPI** services I also run myself on Docker.

- 🏢 **Currently** — Software Engineering Intern at **Cyberverse**: realtime clinical AI (voice + retrieval + imaging), React 19 / Vite consoles, Expo companion app
- 📱 **Mobile** — Flutter (Riverpod, GoRouter, Firebase, RBAC) and React Native / Expo; from 25+ screen education platforms to production recipe and clinician apps
- 🧠 **AI systems** — OpenAI Realtime, Claude, Gemini, vector search (Mongo Atlas / Qdrant), Telegram agents, local inference (Ollama)
- 🖥️ **Full-stack** — Next.js App Router, Express, FastAPI, PostgreSQL, Redis, Socket.IO, Turborepo monorepos
- 🤝 **Open to** — Flutter / React work, realtime systems, and AI-backed product engineering
- 📫 [omer@omerfarukay.com](mailto:omer@omerfarukay.com) · [omerfarukay.com](https://omerfarukay.com)
